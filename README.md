Entry for the [make.fun bounty "One Emoji, One Smile"](https://make.fun/bounty/u-0xkianno-one-emoji-one-smile-5470751f): send exactly one emoji, the one most likely to make a stranger smile. A judge compares entries two at a time and picks the warmer of the pair.

## The emoji

🧸 — a teddy bear.

A teddy bear is warm at first glance: soft, familiar, a small hug from a stranger. Every age and background reads it the same way, with no irony or in-joke that could land wrong — and it feels deliberately chosen, a comfort object, not the first smiley that comes to mind.

## How it works

`main.py` writes exactly that one emoji to `/output/entry.txt` — deterministic, no trailing newline, so the sealed gate sees exactly 1 character of UTF-8 text:

```sh
python3 main.py
```
